## ox journal since

Dump journal entries from the last <duration>

```
ox journal since <duration> [flags]
```

### Options

```
      --all-teams       merge entries across every registered team context
      --format string   output format: content|json|text (default: content) (default "content")
  -h, --help            help for since
      --layer string    layer to read: daily|weekly|monthly|auto (default "auto")
      --limit int       cap the number of entries returned (default 100)
      --team string     team slug, id, or name (defaults to the repo's active team)
```
