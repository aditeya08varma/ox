## ox journal

Inspect the team memory journal

### Synopsis

Read-only commands for listing and showing entries in memory/daily, memory/weekly, and memory/monthly under a team-context root.

### Options

```
  -h, --help   help for journal
```

      --profile          generate CPU profile and execution trace for performance analysis (default: false)
