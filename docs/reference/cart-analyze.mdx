## ox cart-analyze

Dump cart + session + murmur data for AI analysis

### Synopsis

Reads carts (planned work), sessions (work evidence), and murmurs
(coordination signals) for a time range and outputs structured JSON.

Designed for consumption by Claude Code or Claude Cowork for visualization.

```
ox cart-analyze [flags]
```

### Options

```
  -h, --help           help for cart-analyze
      --since string   Start of time window (e.g. 24h, 7d, 2026-03-20) (default "24h")
      --until string   End of time window (default: now)
```
