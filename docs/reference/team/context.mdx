## ox team context

Output a team's context for AI planning

### Synopsis

Output a team's discussions and distilled context for AI planning.

Without arguments: outputs this repo's team context. With a team slug: outputs
that team's context. This is the same context surfaced to AI coworkers by
'ox agent team-ctx'.

```
ox team context [slug] [flags]
```
